# استقرار موازی هسته PasarGuard برای POMP NET

این پوشه یک استقرار مستقل و موازی از هسته رسمی PasarGuard است. سرویس فعلی Marzban و دیتابیس آن را تغییر نمی‌دهد.

## پیش‌نیاز مهم
این Compose برای VPS لینوکسی با Docker Compose و دسترسی شبکه host طراحی شده است؛ برای Railway مناسب نیست، چون از `network_mode: host` و مسیر volume میزبان استفاده می‌کند. برای Railway باید image و پیکربندی مخصوص همان پلتفرم جداگانه ساخته و تست شود.

## راه‌اندازی روی VPS
1. ابتدا از کل Volume فعلی Marzban و فایل‌های تنظیمات نسخه پشتیبان بگیر.
2. این فایل را در یک پوشه جداگانه روی VPS قرار بده.
3. فایل `.env` را طبق مستندات رسمی PasarGuard بساز؛ هیچ رمز یا توکنی را داخل Git قرار نده.
4. اجرا:
   ```bash
   docker compose -f docker-compose.yml up -d
   docker compose -f docker-compose.yml logs -f pasarguard
   ```
5. طبق راهنمای رسمی، کلید موقت owner را بساز:
   ```bash
   docker exec -it pompnet-pasarguard pasarguard cli generate-temp-key
   ```
   سپس با کلید یک‌بارمصرف حساب owner را از داشبورد ایجاد کن.

## مواردی که هنوز انجام نشده‌اند
- این سرویس هنوز به داشبورد سفارشی فعلی POMP NET وصل نشده است.
- کاربران، رمزها، حجم، تاریخ انقضا، شناسه اشتراک و inboundهای Marzban هنوز منتقل نشده‌اند.
- پورت 2096، دامنه، TLS، مسیر اشتراک و اتصال بیرونی v2rayNG در این فایل فعال یا تأیید نشده‌اند.
- image با برچسب `latest` برای شروع موازی استفاده شده؛ پیش از تولید نهایی باید نسخه ثابت انتخاب و pin شود.

## مهاجرت امن
تا وقتی تعداد کاربران و سهمیه‌ها تطبیق داده نشده و لینک اشتراک در v2rayNG از یک شبکه بیرونی تست نشده، DNS یا سرویس اصلی را جابه‌جا نکن. Volume قدیمی را نگه دار تا rollback ممکن باشد.

## مجوزها
هسته PasarGuard تحت AGPL-3.0 منتشر شده است. هرگونه تغییر و ارائه سرویس شبکه‌ای باید الزامات انتشار کد منبع متناظر و حفظ اعلان‌های مجوز را رعایت کند.
