تنظیمات و مهاجرت

Staging
مقادیر محرمانه مانند آدرس API، نام کاربری، رمز، API Token، کلید Adapter و آدرس اشتراک باید در Variables سرویس Railway تنظیم شوند؛ این صفحه فقط وجود تنظیمات را بدون افشای مقدار بررسی می‌کند. برای تغییرشان باید دسترسی Developer یا بالاتر به Railway داشته باشید.
ابزار انتقال Marzban به 3X-UI در این شاخه به‌صورت Dry-run-first آماده شده است؛ اجرای انتقال واقعی هنوز از این داشبورد فعال نشده و تا قبل از تهیه پشتیبان و تطبیق Inboundها نباید اجرا شود. نگاشت لینک‌های قدیمی اشتراک نیز فقط پس از import واقعی قابل تأیید است.

ساخت اینباند اختصاصی POMP NET

SideRail Official API

فهرست و وضعیت اینباندها مستقیماً از API رسمی SideRail خوانده می‌شود. ساخت سفارشی در API عمومی این نسخه ارائه نشده است. قبل از ساخت، اتصال هسته را از «مرکز اتصال» بررسی کن.

پیش‌فرض‌ها WebSocket بدون TLS هستند؛ برای اتصال عمومی باید TLS روی Reverse Proxy یا خود سرور تنظیم شود. پورت‌های پیشنهادی 2053، 2083 و 2087 هستند؛ اگر اشغال باشند، ساخت آن مورد رد می‌شود. هیچ پورت Railway TCP/443 فرض نشده است.
